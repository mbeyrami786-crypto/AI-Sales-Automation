# AI Sales Automation

An AI-powered Excel sales analysis and reporting automation system.

## Features

- Upload Excel sales files
- Automatic revenue calculation
- Sales data analysis
- Best-selling product detection
- Best-performing region detection
- Automatic Excel report generation
- Web interface using Streamlit

## Technologies

- Python
- Pandas
- OpenPyXL
- Streamlit
